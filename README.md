# Sanchay - Frontend (Offline SHG Ledger)

An offline-first PWA for SHG women to manage savings, loans and meetings without internet. Visual graph-based tracking.

### Tech Stack
- React + Vite
- IndexedDB (db.js) for Offline Storage
- Chart.js / Graph Visualization
- PWA Ready

### How to Run
1. `npm install`
2. `npm run dev`
3. Open http://localhost:5173

### Key Features
- 100% Offline Working - No internet needed
- Add Groups, Members, Transactions
- Visual Graph of Savings & Loans
- Auto-sync when online (with Backend API)
- Simple UI for rural users

### Project Structure
- `src/App.jsx` - Main App
- `src/db.js` - Offline IndexedDB logic
- `src/components/` - UI Components
